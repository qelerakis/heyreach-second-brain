# HeyReach CLI is here 🎉

Source: https://www.heyreach.io/blog/heyreach-cli-is-here

Summary: Launch campaigns, pull pipeline, and write messages — all from the terminal. Connect HeyReach CLI to Claude and turn commands into decisions.

The HeyReach CLI is live. Run LinkedIn outreach from your terminal or straight from Claude — without ever opening a browser tab.

Everything you'd do in the HeyReach dashboard is now scriptable. Launch campaigns, pause them, write relevant messages, and pull pipeline numbers—all from the command line you already live in. Connect it to Claude and it stops being a set of commands and starts making real decisions: segmenting lists, writing messages, building reports, replying to warm leads in seconds.

## What you can do with HeyReach CLI:

→ **Launch, pause, and edit campaigns** — full campaign control from the terminal, no dashboard required

→ **Write and send relevant messages** — drafted from your data, not a generic template

→ **Pull pipeline on demand** — replies, sentiment, meetings, ROI, in plain English

→ **Wire it into Claude** — hand it an instruction and let it run the whole play

## Claude Skills built for GTM operators

We shipped two reusable Claude skills so you're not starting from a blank prompt:

→ **Launch campaigns** — push qualified leads and the right signals into HeyReach, then let your agent build the campaign and write the messages. One instruction, a full outbound motion. [Download here](/cli)

→ **Measure pipeline** — "How's last week's campaign doing?" Claude pulls replies, sentiment, meetings, and ROI from HeyReach and tells you what's actually working. [Download here](/cli)

### Why it matters

Your campaigns now live in the same place as your prompts, your data, and the rest of your stack. No tab-switching, no context loss. Outreach belongs where you work.
