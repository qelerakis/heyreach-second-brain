# HeyReach MCP: Build and launch campaigns end to end

Source: https://www.heyreach.io/blog/heyreach-mcp-build-and-launch-campaigns-end-to-end

Summary: HeyReach MCP now lets you build and launch campaigns end to end from any LLM. Clone templates, assign senders, set schedules, and go live in a single prompt.

8 new MCP tools are live. You can now run a full campaign without touching the app.

You can create, configure, and launch a campaign end to end straight from your LLM—Claude, Cursor, whatever you're running. Describe what you want, and HeyReach MCP builds it.

## What's new wit HeyReach MCP update

→ **CreateCampaign** — spin up a fully configured campaign in draft

→ **CreateCampaignFromTemplate** — clone an existing campaign instead of starting cold

→ **UpdateCampaignSequence** — create or replace the entire workflow sequence

→ **UpdateCampaignSettings** — change name, lead list, and exclusions

→ **UpdateCampaignSchedule** — set the time window, active days, and timezone

→ **UpdateCampaignAccounts** — swap the assigned LinkedIn accounts

→ **GetCampaignSequence** — pull the campaign's full workflow tree

→ **StartCampaign** — activate a draft and send it live

## Why it matters

You can now say: *"Clone my best-performing campaign, swap in this lead list, assign my three warmest senders, set it to send 9-5 CET on weekdays, and launch it."*

The MCP handles every step. Draft to live, in one prompt.

A few things this unlocks:

→ **Spin up campaigns from signals.** Wire intent data into your stack and have the MCP build a campaign the moment a trigger fires.

→ **Template once, deploy infinitely.** Clone your winners and adapt them per segment without rebuilding from scratch.

→ **Manage outbound from where you already work.** No tab-switching. Your campaigns live in the same place as your prompts, your data, and the rest of your GTM stack.

This is what we mean when we say LinkedIn outreach should live in your stack, not a browser tab.
