## Inbound-led outbound: Turn inbound signals into a predictable pipeline

- **strategies/playbooks:** Inbound-Led Outbound (ILO) = outbound "triggered, informed, and prioritized by inbound signals," not static lists. 3-part model: (1) IDENTIFY — capture high-intent signals (website behavior, LinkedIn engagement with content, repeated content consumption, buying-stage asset interaction); (2) LEVERAGE — enrich, score, prioritize (ICP fit? company fit? signal strength? worth immediate outbound?); (3) OUTREACH — execute while signal is hot. Concrete HeyReach-centered workflow: 1) buyer intent shows up via Trigify (LinkedIn engagement) then pushed via Make/Zapier/API into a list HeyReach acts on; 2) Clay enriches+ranks (role/seniority, company size/industry, LinkedIn profile data, custom scoring = ICP fit + signal strength), rules filter first so only qualified leads enter (keeps volume controlled, sender health intact); 3) HeyReach adds leads to prebuilt LinkedIn sequence, distributes across multiple senders, each respects daily connection/message limits, auto sender rotation; 4) LinkedIn + email run in parallel for stronger signals via Instantly; 5) all replies land in Unified Inbox with tags (interested, ask later, not now); 6) statuses sync back to HubSpot (lead status, logged conversations, follow-up tasks); 7) performance feedback (which signals to replies, acceptance/response rates per sequence, sender-level perf). Speed rules: SAME-DAY for strong inbound signals; WITHIN A FEW HOURS for high-intent actions (pricing, comparison pages, buying guides); NEVER "next week."
- **frameworks/methods/tools:** ILO / I-L-O model (Identify-Leverage-Outreach). Stack: Trigify (LinkedIn engagement signals), Clay (enrichment + scoring), Make/Zapier/HeyReach API (piping signals to lists), HeyReach (execution engine), Instantly (parallel email), HubSpot (CRM sync). Success metrics: signal-to-first-touch time, reply rate by signal type, inbound-assisted outbound conversion, meeting rate per enriched signal, pipeline velocity (not lead volume).

ILO is explicitly NOT "warm outbound," NOT "ABM with better copy," NOT "sending messages because someone visited your site." "volume is the first thing platforms punish." Schedule DTO: dailyStartTime/dailyEndTime (TimeSpan, max "24:00:00", start<end), timeZoneId (IANA, default "Etc/GMT"), enabled Mon–Fri default true / Sat–Sun default false, startDate/endDate (DateOnly?). Validation: every path ends in END; CONNECTION_REQUEST + CHECK_IS_CONNECTION + CHECK_IS_OPEN_PROFILE require BOTH branches; all other non-END nodes require unconditionalNode only.

## Lead prioritization on LinkedIn: Respond to high-intent leads first
- **source_type:** blog_post
- **source_url:** https://www.heyreach.io/blog/lead-prioritization
- **topics:** inbox-reply-management, sales-process, lead-generation, heyreach-product, ai-outreach, analytics-benchmarks
- **strategies/playbooks:** A reply-triage system built in HeyReach Unibox so SDRs work high-intent replies first (not chronologically). Four components: priority tags, filters, action routing, daily loop. FOUR tags (use exactly four): Hot Lead (explicit buying intent / clear next step — "What's the pricing?", "Who's the decision-maker here?", "Can you send a case study?"); Needs Nurture (interest, no urgency — "Can you send more info?", "I'll review and get back to you"); Follow Up Later (timing objection not rejection — "Not right now", "Reach out next quarter"); Low Priority (no pipeline value — "Wrong department", "Not a fit"). Filters (every rep sets the same core set): Tag + Unread + Sender + Campaign. Tag→action mapping: Hot Lead = respond immediately + Add to campaign (AE handoff or demo sequence); Needs Nurture = share info + Add to nurture campaign; Follow Up Later = tag only (no snooze needed); Low Priority = archive/ignore. Daily triage loop (10 min, run 1–2×/day morning + afternoon): open Unibox → apply Unread filter → tag every new reply by intent → switch to Hot Lead filter → answer all Hot Leads top-down → clear untagged. Full setup ~20 min. Interest indicators: buying-intent cues ("pricing," "next steps," "timeline," "budget"), decision-maker language ("I'll bring this to the team"), clear timelines, meeting/demo requests. Pro tip: when torn between Hot Lead and Needs Nurture, pick Hot Lead. Automation: IF reply tagged Hot Lead THEN Slack-notify AE or create CRM task.
- **frameworks/methods/tools:** "Unibox prioritization engine" (tags/filters/routing/loop — explicitly "no complex machine learning, no AI layers"). MCP Assist with Claude for faster triage: summarize replies, surface buying-intent cues, extract the core question/objection, detect decision-maker authority — with example rep prompts. Emphasis: "MCP is the connection protocol, it does not tag, route, or prioritize conversations on its own" — reps keep control.
- **product/features:** HeyReach Unibox (priority tags, Tag/Unread/Sender/Campaign filters, add-to-campaign routing); HeyReach Dashboard (managers track loop-completion metrics without micromanaging); integrations for Hot Lead → Slack/CRM automation; MCP + Claude.
