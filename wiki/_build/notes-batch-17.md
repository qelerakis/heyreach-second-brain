## Why automation fails in sales sequences: 8 early-warning signs of outbound drift

- **strategies/playbooks:** 8 behavioural early-warning signals of outbound drift + fixes: (1) Acceptance rate drops vs 4–8 week baseline → tighten ICP filters, split lists, refresh only the first touch. (2) Reply volume stable but quality declines → pull 20 recent Unibox replies, tag Interested/Not now/Not relevant; rising "Not relevant"=ICP fix, rising "Not now"=timing/offer fix. (3) Early-stage message fatigue → rotate 1–2 alternate openers with different relevance hooks, shrink the CTA, re-anchor to "why now." (4) Pending invites backlog grows → set connection requests to withdraw after 7–14 days, lower daily connection pacing, rebalance across senders, reconfirm sending limits/working hours. (5) Sequence progression stalls in early steps → early actions (profile views/likes before connect step) consume shared daily limits; raise the limiting step's cap OR reorder sequence. (6) Reply latency spikes → build daily Unibox routine filtering Unanswered, tag before reply, respond to intent first, use saved replies; response >24–48h hurts outcomes. (7) Sender imbalance → normalize daily limits/working hours across accounts, reduce campaigns per sender, rotate responsibility. (8) CRM ↔ HeyReach lifecycle drift → pick one source of truth (usually CRM), push LinkedIn outcomes + Unibox tags to CRM via Zapier, enforce stop logic in Zapier/n8n. Weekly 5-minute health check: export last 7 days from Dashboard, compare acceptance/reply WoW, check pending invites + pacing limits, scan Unibox for untagged positives, verify CRM sync mappings.
- **frameworks/methods/tools:** Three-state outbound health model — 🟢 Green (within baseline, monitor weekly, don't tweak), 🟡 Yellow (1–2 signals slipping, optimize mid-sequence, refresh opener, clean data before adding volume), 🔴 Red (multiple signals stacking, pause affected campaigns/senders, fix root cause, resume with safeguards). Zapier / n8n for CRM sync + stop logic; HeyReach MCP for AI-assisted reply intent tagging (Claude/ChatGPT), operator reviews output.
- **product/features:** Where to detect each signal in HeyReach surfaces — Dashboard (trend detection, sender-level anomalies; NOT intent), Dashboard exports/API (confirm drift over 4–8 wk ranges; NOT real-time), Unibox (reply quality/latency/triage; source of truth for replies), Campaigns screen (lead progression states: Pending/In sequence/Finished/Failed; flow health not root cause), Sending Limits & Working Hours (per LinkedIn account, SHARED across campaigns — early steps can throttle later ones), Master View (cross-workspace pattern spotting). Find Email fallback step. LinkedIn → Instantly handoff for non-responders. HeyReach tags pushed to CRM as "glue."
